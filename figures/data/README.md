# Inputs to the figures

These files are generated by `python figures/scripts/make_data.py` from the repository root. The underlying evidence remains in [data/](../../data/README.md).

| File | Contents |
|---|---|
| `certified.csv` | Every stored design's normalised stiffness, solid fraction, base Poisson ratio and isotropy defect, with an acceptance indicator |
| `headline.csv` | The same columns for the headline anisotropic-base family |
| `baseline.csv` | HS, void, slip-limit and sampled dust coordinates for each case |
| `gaps.csv` | Maximum sampled corner gaps before and after adding accepted designs, with the maximising angles |
| `support.csv` | Both gaps at each sampled angle in degrees |
| `finite_scale.csv` | All stored wall comparisons, including scale ratio, resolution and relative tensor error |
| `wall_geometry.json` | The binary herringbone section and its exact periods, reconstructed from the stored finite-scale case |
| `headline_geometry.json` | A copy of the headline geometry at base Poisson ratio 0.3 and solid fraction 0.1 |

At the finest stored wall fraction, the tables retain the largest bulk coordinate, smallest shear coordinate and largest isotropy defect across void regularisations. Acceptance requires defect at most 0.001. Rejected rows and tiny negative bulk coordinates remain in the CSV; the plotting script applies the [display conventions](../../docs/methods.md). Table generation uses the stored finite-scale errors; `reproduce.py` independently recomputes them from tensors.
