# The result in pictures

`stiffness-map.png` places all 555 accepted designs against the HS square and baseline constructions. Zero-bulk diamonds overlap on the left edge without jitter; the solid-fraction colour key labels discrete values. `corner-gap.png` compares the sampled support gap for all 14 headline cases. Both maps include separate panels for the two base solids.

`wall.png` is the high-resolution still and poster of the exact finite-scale herringbone mask: a cutaway of the full section beside a magnified crop. Blue and copper identify opposite plate orientations of the same solid; the solid layers are light grey. `wall.mp4` changes only the camera angle. `wall.gif` is its continuously looping inline version, with 48 frames at 8 frames per second and 1100 by 619 pixels. The [geometry description](../docs/finite-scale.md) gives the exact crop and cutaway. This is an individual wall test, not the complete headline tree.

`wall-convergence.png` shows all 11 direct-simulation comparisons. A filled circle and larger hollow ring retain the two overlapping resolution checks. Thin segments join observations; the dashed inverse-ratio line is a slope guide, not a fit. Vector versions accompany all three plots.

The [top README](../README.md) supplies descriptions and interpretation. The [source data](../data/README.md) remain usable without images. GitHub displays the animated GIF inline, linked to the MP4.

[Regeneration commands](scripts/README.md) rebuild the figure tables, all three plots, the wall image, its orbit and the GIF using only the included evidence. The [figure inputs](data/README.md) retain the values before plotting transformations.
